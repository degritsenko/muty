# Muty Session Management

Terms for saved SSH sessions, their organization, recovery and terminal use.

## Language

**Session**:
A saved connection configuration that can be opened in a terminal tab.

**Session folder**:
A named grouping of sessions that can contain nested folders.
_Avoid_: Directory (when referring to the saved-session grouping)

**Configuration backup**:
A portable snapshot of sessions and their associated settings.

**Restore**:
Applying selected data from a configuration backup while resolving conflicts with current sessions and credentials.

**Authentication attempt**:
One effort to establish an SSH connection, including authentication through its optional jump host.

**Terminal appearance**:
The font and color settings used to display terminal output.
