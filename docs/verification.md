## Решения при реализации

- Работа в запрошенном ~/k8s/muty на codex/muty-mvp, без отдельного worktree.
- Unit-тесты не добавлены по явному требованию пользователя.
- Native backend SwiftPM: установленный XCBuild не инициализируется. Риск: native backend устаревает, потребуется адаптация к будущему toolchain.
- ViewState alias сохраняет обычный SwiftUI property wrapper без отсутствующего в CLT SwiftUIMacros plugin.
- Saved-password режим отключает ProxyJump/ProxyCommand: защита от выдачи пароля jump-процессу, ценой необходимости ручного входа через bastion.
- Подтверждение нового host key — отдельный диалог ASKPASS с полным fingerprint; классификация сверена с исходником OpenSSH 10.3p1.
- Изменение пароля/адреса отзывает ожидающую авторизацию старых вкладок; может потребоваться reconnect, зато новый секрет не уйдёт прежнему endpoint.
- Disconnect завершает принадлежащую SSH process group; выход приложения ждёт cleanup через terminateLater.
- Same-UID malware, полное обнуление String и перенаправления доверенного SSH config вне модели защиты.

## Не проверено без SSH-сервера

Успешный и неверный пароль; Keychain locked/denied; новый/изменённый host key;
ключи, OTP, vim/top, resize удалённой сессии; shutdown во время реальной аутентификации.
Не считать saved-password flow проверенным end-to-end до выполнения этих сценариев.

## Отложено после ревью

Minor: редактор разрешает пароль почти 16 КБ, OpenSSH ASKPASS читает не более 1023 байт.
Использовать пароль до 1023 UTF-8 байт; добавить явную валидацию в следующей правке.
